# 和弦進行音準練習 · Chord Progression Pitch Trainer

TCMC Harmony Ears 系列第 4 個網頁 App。選一條和弦進行、選調、選你要唱的聲部，跟著節奏一路唱過整條和弦進行，麥克風即時偵測音準。中英雙語介面。

Part of the TCMC Harmony Ears suite. Pick a chord progression, a key, and the voice part you want to sing, then sing your part through the whole progression in time, with real-time microphone pitch detection. Chinese / English interface.

- Live app: https://tcmctw.github.io/chord_progression_practise/
- Manual (中文 / EN): see `manual/`

Better use wired earphones — Bluetooth earphones may get poor microphone input quality and cause inaccuracy. If there is no sound on your phone, try pressing the close/open microphone button to activate sound.
